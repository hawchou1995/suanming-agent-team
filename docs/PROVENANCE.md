# 知识来源与已知缺陷

## 1. 来源

本团队的知识整理自 **高山青 编著《世界相命全集》**（10 册）：
手相 / 面相·血型 / 指纹占卜 / 十二支·姓名学·星相 / 易经与八卦·灵数占卜 /
吉普赛魔牌 / 扑克牌占卜 / 紫微斗数 / 四柱与八字 / 奇门遁甲·堪舆风水。

版权归原作者及出版方所有；本仓库不含其正文，见 `../NOTICE.md`。

## 2. 抽取路径（决定了知识质量的边界）

源件为**纯扫描件**：每页无文本层、每页恰好一张扫描图。
因此知识经由 OCR 得到，而不是原生文本。

| 环节 | 实情 |
|---|---|
| 文本来源 | OCR（扫描件 → markdown） |
| 实测字符错误率 | **约 5–10%** |
| 已确认错例 | 霜峰→霜降、敷雨→穀雨、奏丑→癸丑、千支→干支、力宮→九宮、县表→萬年表、锲而不舍→鍥而不捨 |
| 文本语体 | **繁体中文**，知识一律保留繁体原样，未强行转简体 |

**这意味着**：数值（干支序列、节气局数、笔划数）多数可靠但**仍可能有个别误读**；
凡标 `^[ambiguous]` 处须以原书为准。

## 3. 已知不可复原项（诚实边界）

以下内容在文本层**确实缺失**，本团队不会编造，会明确说明：

- 原书**插图**内容（文本模型不可见；需视觉能力 + 可选数据包的图片）
- 部分**表体在 OCR 中被毁**的表格（仅存表名与少量样例值）
- 个别条目的**整行缺失**（如某些型的若干栏位）
- **版权页/版次**信息在多数册不可考

## 4. 为什么门类内核对缺陷是「显式」的

每个内核都带一段缺陷声明，把上述边界写在提示词里。
这样 agent 在缺资料时**会说「不知道」**，而不是用通用知识补齐——
后者会让一套有出处体系的术数回答退化成泛泛而谈。
