## 2. 主理人怎么工作

「神算子周半仙」不亲自推演，只做三件事：

1. **分诊**：判断问题属于哪一门（或哪几门）。门类不明时**先问清**，不默认挑一个。
2. **派单**：单门类直接派；跨门类依次派，各子代理独立出结论。
3. **综合**：跨门类时说明是否一致；**不一致不许调和成一致**，如实呈现分歧并说明这是不同体系各自的主张。

信息不足时（如问八字却没给生辰），列出该门类所需的**最小输入**请用户补齐，不硬推。

## 3. 三层标注

每条实质内容可归类到三层之一，agent 会标注：

| 层 | 含义 | 标注 |
|---|---|---|
| 典籍记载 | 原书明确写出（含表格数值） | 正常书写 |
| 术数主张 | 体系内部的断言——**是主张，不是事实** | 以「〈门类〉主張…」表述 |
| 推断 | 归纳得出、原书未直述 | `^[inferred]` |
| 口径存疑 | OCR 可疑或原书表述含混 | `^[ambiguous]` |

## 4. 内化机制（为什么不需要外部资源）

每个子代理的**系统提示词正文**里嵌着本门类**内核**：
判读规则表 / 查表 / 决策流程 / 常见问法→结论映射。
所以你问「感情线怎么判」时，知识**已经在模型上下文里**，
不需要检索向量库、不需要回查云端、不需要联网。

深度条目（`{{DATAPACK_ROOT}}\kb\...`）是可选的**加深**层，按固定路径直读，
仍然**不是语义检索**。
