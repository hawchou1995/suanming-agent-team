## 一、本門類是什麼（判定範圍）

**三元奇門遁甲**是一種**方位術**：判斷「某人於某時往某方位／於某方位動土修造」的吉凶，並求「凶運改為大吉運」。
體系由**三元**構成——**地利**（所用方位的易卦，最重）、**人和**（該方位的人際助力，次之）、**天時**（天上能源隨時間的影響，最輕）；三者互相影響而決吉凶。
依本人是否移動分兩盤：**立向盤**（旅行、移轉、出差——動態）／**坐山盤**（房屋重修、改建、造園、挖溝、打樁——靜態）。
依期間分三盤：**時盤**（15 天以內）／**日盤**（15 天以上～6 個月）／**月盤**（6 個月以上）。
本門類另含**堪輿風水**兩支：**宅相**（住宅方位、格局、隔間吉凶）與**墓相**（墳墓巒頭／三才／理氣吉凶，**只對所葬者直系親屬起作用**），以及**由十干與八門斷吉凶**（墓相盤）。
**不回答**：非方位性的命理問題（八字格局、紫微星曜等）；不給出醫藥、投資、法律結論。
**所需輸入**：①目的（旅行／移轉／重修改建／事業／業務／昇官／財運／戀愛／疾病）②本人移動與否（定立向／坐山）③預定日期時刻或年月④欲往／欲動之方位⑤（宅相）坐向、凹凸、中心點⑥（墓相）四周形勢、門向與牌向。
**體例**：原書聲明表格與例子**都用換算後的陽曆**（p.~6）。時刻以「往目的地途中停留點出發」之時為準；方位以**本宅**為基準（p.~11–12）。

## 四、決策流程

**A. 奇門遁甲（方位吉凶）**
1. **問明目的** → 六種象意之一。
2. **定盤別**：本人移動 → 立向；不動（動土修造） → 坐山。再依期間定時盤（≤15 天）／日盤（15 天～6 月）／月盤（>6 月）。
3. **取時刻與方位**：時刻用「途中停留點出發」之時；方位以**本宅**為基準。
4. **求局數**：
   - 時盤 → 表1 取時干支 → 定「位次」→ 表3（立向）或表3 塗黑格（坐山）。
   - 日盤 → 表12 遁甲曆取「九宮·干支」；立向者局數＝該日九宮；坐山者查表6。
   - 月盤 → 表12 取「月之九宮·干支」（注意自然月區間）→ 表3（立向）或塗黑格（坐山）。
5. **求九宮**：時盤查表2（遁別×日支組×時辰）；日／月盤由表12 直接讀九宮。
6. **求天時與地利**：以時／月干支選表14 頁 → 由九宮與陰陽局交叉 → 得天盤字母（天時）與地利下卦字母。
7. **查象意**：地利上卦 × 下卦 → 對應目的的象意表 → 得大吉／吉／凶／大凶；天時查表5 得 ○／×。
8. **查人和**：表8 定 A／B 類 → 以 A 類選頁 → 找中央格＝B 類之盤 → 讀 ○ 記號數字 → 得人和方位。
9. **綜合**：地利（最重）＞ 人和 ＞ 天時；三者權衡後給吉凶與建議方位。
10. **無吉方時**：先在吉方停留**十小時以上**（僅時盤、僅限 1–2 天）；或先向吉方旅行 100 公里再啟程。

**B. 命數（壽數）**（源 p.~23–30）
1. 表13 取**出生年**干支與九宮（注意有效期限）；由干定陰陽（A C E G I 陽／B D F H J 陰）。
2. 表13 取該月「日之基數」＋出生日數 → 表4 取**出生日**干支與九宮；表2 取**出生時**九宮；表1 取出生時干支。
3. 定順逆：男陽干／女陰干＝順運；男陰干／女陽干＝逆運。
4. 表11 取出生日干支號碼 → 逆運 (號碼−1)÷3；順運 (30−號碼)÷3（零數捨去）＝年運。

6. 死宮：表9 B 欄找出生日九宮為中宮之盤 → 看出生時九宮方位 → A 欄定位盤得**死宮**。

**C. 宅相**（源 p.~70–89）
1. 定**中心點**（A 點與 B 點各判一次，取合斷）。
2. 看**四神相應**（東青龍／南朱雀／西白虎／北玄武）。
3. 量**伸張與欠缺**（取角，看日照與通風）。

**D. 墓相**（源 p.~89–98）
1. **巒頭**：龍（地勢）→ 穴（位置）→ 砂（地質、空氣）→ 水（水流、道路）。
2. **三才**：天（石碑）／人（基石上部）／地（基石）。
3. **理氣**：定**門向**（最近自己墓之入口）與**牌向**（墓碑所對）→ 24 方位 → 墓相盤取號碼。
4. **十干與八門**：查組合斷語（主詞為「子孫…」）；⚠️ 組合與斷語的對應已遺失，只能引述斷語本身。
